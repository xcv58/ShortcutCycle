# Marketing Materials

This folder holds launch plans, posting drafts, and channel-specific marketing assets that are not part of the public website.

## Structure

- `reddit/` - Reddit launch plans, post drafts, reply notes, and moderation playbooks
- `product-hunt/` - Product Hunt launch copy and assets
- `hacker-news/` - Hacker News launch notes and copy
- `shared/` - Reusable messaging, assets, and references shared across channels
